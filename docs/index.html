LogDoctor

Drop in your whole Minecraft server folder, or a single log. It finds what is wrong, puts the fixes in order, and writes the corrected files.

Audit the whole server

Reads every plugin jar, your configs, server.properties, the start script and the latest log, all inside your browser. Nothing is uploaded.
